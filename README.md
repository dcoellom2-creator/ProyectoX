# Sistema RH-250

Paquete estático para GitHub Pages.

## Cómo publicar
1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos y carpetas de este paquete.
3. Ve a Settings > Pages.
4. En Source selecciona Deploy from branch.
5. Selecciona main / root.
6. Abre el enlace publicado.

## Páginas principales
- index.html
- bienvenida.html
- ruta-formacion.html
- herramientas.html
- retos.html
- tareas-evidencias.html
- ranking-progreso.html
- perfiles.html
- liderazgo.html
- preguntas.html
- comunidad.html
- soporte.html
- admin.html

## Notas
- La página de tareas guarda datos en localStorage del navegador y exporta CSV.
- Para producción se recomienda conectar registro y evidencias a Google Forms, KoboToolbox o Google Apps Script.
- Reemplaza el enlace de WhatsApp en comunidad.html.
