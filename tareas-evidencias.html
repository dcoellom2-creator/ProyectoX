Criterios de revisión

Una evidencia se considera válida cuando permite verificar la acción realizada.

¿Qué debe tener una buena evidencia?

Nombre del participante, fecha, módulo, actividad, producto entregado y enlace o captura verificable.

¿Qué no cuenta como evidencia?

Decir “ya lo hice” sin archivo, captura, link o explicación mínima.

¿Quién revisa?

Primero el facilitador de célula. Luego se valida una muestra desde el panel general.
